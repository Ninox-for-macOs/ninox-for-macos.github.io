Ninox

A simple flat-file database system for Mac. Manage data effortlessly with tables, forms, calculations, and powerful relations—all in one intuitive app.

Tables and Views

Browse, filter, sort, and group your data in flexible tables. Jump to information instantly with fast full-text search at the core.

Rich Data Fields

Handle text, numbers, yes/no, lists, dates, times, pictures, and web addresses. Link tables via relations to model complex relationships.

Forms and Automation

Build drag-and-drop forms for clean data entry. Add spreadsheet-like calculations across records and linked tables.

Visual Insights

View date-based entries in a clear calendar. Generate diagrams with a tap to visualize the current state of your data.

Secure and Exportable

Control access with roles and rights. Export to Excel for further analysis—your data stays yours.

How It Works

Step 1: Create Tables

Step 4: Share Securely

Assign roles, export data, and collaborate with precise permissions.
